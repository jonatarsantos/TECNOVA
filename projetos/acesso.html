01 · CONCEITO

O que é RFID?

RFID significa identificação por radiofrequência. Um leitor comunica-se com uma etiqueta ou cartão compatível para obter seu identificador. O controlador compara esse identificador com os dados autorizados e decide qual resposta executar.

02 · OBJETIVO

O que vamos construir?

Um protótipo didático que reconhece cartões previamente cadastrados e indica acesso permitido ou negado. Em uma montagem física, um LED ou uma fechadura apropriada pode representar a resposta do sistema.

MATERIAIS E PREPARAÇÃO

Componentes do projeto

Confira o que cada componente faz antes de montar o protótipo.

Hardware necessário

  • Arduino Uno ou placa compatível.
  • Leitor RFID compatível, como o MFRC522.
  • Cartão ou chaveiro RFID compatível com o leitor.
  • LEDs e resistores para sinalizar o resultado.
  • Protoboard e fios jumper.
  • Cabo USB e computador com Arduino IDE.

Conhecimentos utilizados

  • Entradas e saídas digitais.
  • Comunicação entre placa e módulo.
  • Condicionais: permitido ou negado.
  • Leitura e comparação de identificadores.
  • Testes e depuração de um protótipo.

Atenção: o MFRC522 normalmente utiliza lógica de 3,3 V. Confira a tensão e a ligação indicadas na documentação do módulo antes de conectar a placa.

ETAPAS DO SISTEMA

Como funciona?

O processo começa quando o cartão é aproximado do leitor.

Leitura do cartão

O leitor RFID detecta um cartão compatível e obtém seu identificador.

Verificação

O controlador compara o identificador com os cartões autorizados cadastrados.

Resposta

O sistema apresenta o resultado e, na montagem real, aciona a saída correspondente.

PROGRAMAÇÃO

Exemplo de lógica em Arduino

O trecho abaixo demonstra a decisão de autorização. Ele é um exemplo didático de lógica, não um programa completo para o MFRC522: a leitura real do cartão e a configuração dos pinos precisam ser implementadas para o hardware escolhido.

Arduino / C++ · exemplo de decisão 
const String cartaoAutorizado = "A1B2C3D4";

bool verificarCartao(String identificador) {
  return identificador == cartaoAutorizado;
}

void processarLeitura(String identificador) {
  if (verificarCartao(identificador)) {
    Serial.println("Acesso autorizado");
    // Exemplo: sinalizar com LED verde.
  } else {
    Serial.println("Acesso negado");
    // Exemplo: sinalizar com LED vermelho.
  }
}

void setup() {
  Serial.begin(9600);
}

void loop() {
  // Integre aqui a leitura do módulo RFID.
}

Em uma aplicação real, não use apenas o UID do cartão como proteção de alto nível: identificadores podem ser copiados. Adote mecanismos de autenticação adequados ao risco.
