Água na medida certa com irrigação automática.

Um sistema inteligente acompanha a umidade do solo e pode acionar uma bomba quando a terra estiver seca. O objetivo é ajudar a cuidar das plantas e evitar a irrigação desnecessária.

01 · CONCEITO

O que é irrigação automática?

É um sistema que utiliza sensores e um controlador para decidir quando irrigar. Em vez de depender apenas de horários, o projeto pode usar a condição do solo como referência para acionar ou desligar uma bomba ou válvula.

02 · OBJETIVO

Como a automação ajuda?

O protótipo demonstra como monitorar a umidade, definir um limite de acionamento e controlar a irrigação. Os resultados dependem do sensor, da planta, do solo e da calibração.

MATERIAIS E PREPARAÇÃO

O que será necessário?

Hardware necessário

  • Arduino Uno ou placa compatível.
  • Sensor capacitivo de umidade do solo.
  • Bomba de água de baixa tensão ou válvula adequada.
  • Módulo de acionamento compatível com a bomba.
  • Mangueira, reservatório e recipiente para a planta.
  • Fonte adequada, fios e protoboard para o circuito de controle.

Conceitos importantes

  • Leitura de entradas analógicas.
  • Calibração de sensores.
  • Uso de limites para tomada de decisão.
  • Acionamento de cargas com módulo apropriado.
  • Monitoramento do consumo de água.

Não ligue uma bomba diretamente a um pino do Arduino. Utilize um circuito de acionamento dimensionado para a carga, com alimentação apropriada e proteção elétrica.

ETAPAS DO SISTEMA

Do solo seco à irrigação

Medir

O sensor fornece uma leitura relacionada à umidade do solo.

Comparar

O Arduino compara a leitura com um limite definido após a calibração.

Irrigar

Se necessário, o controlador aciona a bomba por um circuito apropriado e verifica novamente a condição do solo.

PROGRAMAÇÃO

Exemplo de lógica em Arduino

O exemplo mostra a comparação de uma leitura analógica com um limite. Os valores dependem do sensor e devem ser calibrados. O trecho não deve acionar uma bomba sem o circuito de potência adequado.

Arduino / C++ · exemplo didático 
const int pinoSensor = A0;
const int limiteSeco = 600;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int leitura = analogRead(pinoSensor);

  Serial.print("Leitura do sensor: ");
  Serial.println(leitura);

  if (leitura > limiteSeco) {
    Serial.println("Solo possivelmente seco");
    // Acionamento deve ser integrado
    // a um módulo apropriado.
  } else {
    Serial.println("Umidade dentro do limite");
    // Manter a bomba desligada.
  }

  delay(1000);
}

Em muitos sensores analógicos, a leitura aumenta quando o solo está mais seco, mas isso varia por modelo. Calibre o sensor antes de definir o limite e teste o comportamento com segurança.
